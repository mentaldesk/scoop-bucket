# scoop-bucket

A [Scoop](https://scoop.sh) bucket for mentaldesk tools.

## Install

```powershell
scoop bucket add mentaldesk https://github.com/mentaldesk/scoop-bucket
scoop install tuicode
```

## Apps

| App | Description |
| --- | --- |
| [tuicode](https://github.com/mentaldesk/TuiCode) | Minimalist terminal code editor for working over SSH |
